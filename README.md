# Thermostat-ESP32
Thermostat connecté ESP32 simulé sur Wokwi avec supervision Blynk IoT. 
Mesure température (DS18B20 + DHT22), contrôle chauffage/climatisation via hystérésis ±0.5°C, affichage LCD I2C, alertes critiques et programmation horaire mode éco. 
Simulation : https://wokwi.com/projects/466013324897927169
